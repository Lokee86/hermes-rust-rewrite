# Weixin stock plugin implementation spec

Register personal WeChat as a bundled `weixin` adapter using Tencent's iLink Bot API. Start after both WeCom modes and the shared contract pass. A headless profile can privately enroll a bot, serve authorized DMs, exchange encrypted CDN media and reopen the saved poll position and conversation context. Group delivery is capability-gated because iLink commonly withholds ordinary group events. [Shared gateway contract](ADAPTER_CONTRACT.md#shared-requirements-for-stock-plugins) · [WeCom spec](WECOM_ADAPTER_SPEC.md) · [Hermes Weixin guide](https://github.com/NousResearch/hermes-agent/blob/v0.23.4/website/docs/user-guide/messaging/weixin.md) · [Tencent iLink protocol](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md)

## Registration and polling

Put the Rust factory and wire client in `hermes-gateway::messaging::weixin`. The adapter owns iLink enrollment, long poll, CDN protocol and rendering. The profile owner stores verified identity, private secrets, leases, cursors, grants and effects. Use Tencent's current owner-private QR flow and the provider's authorization or verification steps where required. Stage setup state under an expiring owner lease. Accept credentials after verifying the confirmed bot and matching endpoint. Scope token-bearing hosts, including provider-declared regional redirects. An expired account requires reauthorization. Rotation that proves the same account preserves receipts. A different account requires a new binding. [Mercury adapter seam](src/messaging/types.rs) · [Hermes QR flow](https://github.com/NousResearch/hermes-agent/blob/v0.23.4/plugins/platforms/weixin/adapter.py#L587)

Lease one active `getupdates` consumer per account. Commit the dispositions or recoverable handoffs of a returned batch before advancing opaque `get_updates_buf`. Keep the previous position on partial failure and merge repeated copies by authenticated message identity. Separate normal poll timeout, transient errors, rate limits, expired credentials and invalid cursor. Honor bounded server timing hints. On restart reopen account and cursor together. A necessary reset reports any loss of continuity. [Hermes poll loop](https://github.com/NousResearch/hermes-agent/blob/v0.23.4/plugins/platforms/weixin/adapter.py#L812)

## Chat, context and media

Verify the account, source peer, exact provider conversation and message identity. Suppress own echoes. Keep distinct same-text inputs and merge only authenticated copies of a logical message. Debounce compatible short fragments using the durable batching rule. Apply DM allowlist or pairing before protected preparation. Disable groups by default. Enable them only where actual provider events and approved sends identify the exact group, with separate group and actor policy. A missing group route cannot become a DM. Preserve authorized quotes and expose text commands, approvals and clarification through native authority. [Hermes access policies](https://github.com/NousResearch/hermes-agent/blob/v0.23.4/website/docs/user-guide/messaging/weixin.md#access-policies)

Treat `context_token` as secret evidence scoped to account, verified conversation or peer, and originating event. Persist it before advancing the cursor, and apply only an authorized later refresh for that destination. Keep typing tickets short lived and peer-scoped. Start and stop typing for admitted work where a current ticket permits. Render supported Markdown with ordered chunks and a conservative 4,000-character budget. Preserve multiline text and code blocks where they fit. [Hermes context tokens and typing](https://github.com/NousResearch/hermes-agent/blob/v0.23.4/website/docs/user-guide/messaging/weixin.md#context-token-persistence)

Resolve authorized images, files, video and voice. Keep the asset's source and quote scope. Validate iLink and CDN origins, ciphertext and decrypted size and the documented AES-128-ECB padding and key representations. Use provider voice transcription where present, or stage the supported encoding for the shared audio pipeline. Outbound images, video and files use an expiring allocation, fresh per-file key, ciphertext upload and encrypted media reference. Preserve the qualified upload receipt across restart. Send captions and attachments in order. Use native supported voice encoding or an authorized file presentation. Keep plaintext, keys and tokens private. [Tencent media protocol](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md#media) · [Hermes Weixin media](https://github.com/NousResearch/hermes-agent/blob/v0.23.4/website/docs/user-guide/messaging/weixin.md#media-support)

## Delivery and recovery

Prepare one stable `client_id` per immutable send part. Classify transport and iLink application status separately from user-visible delivery. An expired context prevents contextual reply. Qualify any provider-permitted later context refresh or tokenless proactive send for that exact verified peer. Require proactive policy for the latter and proven prior non-acceptance before switching a pending effect. Treat `client_id` as correlation until a supported replay guarantee establishes automatic retransmission. An ambiguous send waits for exact evidence or owner resolution. A verified eligible home peer can receive scheduled and manual results using the same outbox after restart. Report the blocked route when the account or provider no longer permits delivery. [Tencent send protocol](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md) · [Hermes send classification](https://github.com/NousResearch/hermes-agent/blob/v0.23.4/plugins/platforms/weixin/adapter.py#L985)

## Implementation and acceptance

| Step | Prerequisite | Evidence |
| --- | --- | --- |
| Private setup and polling | Both WeCom gates and shared conformance | Verified QR enrollment, account leases, durable cursor and batch replay. |
| Sessions, media and outbox | Durable intake | DM and group capability rules, native controls, context freshness and encrypted media round trip. |
| Live acceptance | Transport and shared conformance | Real WeChat bot DM, media and qualified outbound delivery after reconnect and restart. |

Drive scripted iLink enrollment, pulls, configuration, sends and CDN through the production adapter and real profile owner. Cover process loss during a poll batch, duplicates and intentional same-text input, expiring setup and read grants, conflicting account tokens, denied media before CDN access, context renewal, ambiguous send and proactive eligibility. Run shared conformance and `cargo test --locked --workspace`. Verify an authorized and denied peer, typed control, multiline reply, image and voice or file, durable typing/context separation, and an approved home delivery using a real iLink bot. Claim group support only after a real group round trip verifies the exact audience. [Hermes Weixin fixtures](https://github.com/NousResearch/hermes-agent/blob/v0.23.4/tests/gateway/test_weixin_plugin.py)
